# mh-mod-manager

mh-mod-manager 是一款面向《怪物猎人》系列的 Windows MOD 管理器，支持：

- 怪物猎人：世界（MHW）
- 怪物猎人：崛起（MHR）
- 怪物猎人：荒野（MHWilds）

绿色免安装，解压即用。MOD 文件集中存放在程序目录的 `data\` 文件夹内，不污染游戏目录；禁用 MOD 后游戏目录不留任何残留文件。

## 功能一览

- **启用 / 禁用**：一键切换 MOD，关闭后自动清干净已部署的文件
- **分组与优先级**：自定义分组归类 MOD，组内 ↑↓ 调整顺序；MOD 之间覆盖同一文件时，**列表靠后的覆盖靠前的**
- **组件化 MOD**：多组件压缩包（多个子文件夹、散装 PAK）导入为一个 MOD，内部组件可独立开关、自由排序
- **更新 MOD**：用新版本压缩包原地更新，保留分组、优先级和改名
- **改对应装备**：把模型替换类 MOD 改写到另一套游戏内武器/防具，无需改文件
- **Nexus 来源识别**：按 Nexus 下载命名规则自动识别 MOD 页面 id，详情页一键打开对应 Nexus 页面
- **预览与搜索**：自动读取 MOD 封面图，支持按名称、类型、作者、装备搜索

## 安装

1. 前往 [Releases](../../releases) 页面下载 `mh-mod-manager-<版本号>.zip`
2. 解压到任意目录（建议避开游戏目录和需要同步的文件夹）
3. 运行 `mh-mod-manager.exe`

## 快速上手

1. **选择游戏**：左侧点击对应游戏；若未自动探测到安装目录，点击齿轮图标手动选择
2. **添加 MOD**：点击「添加mod」按钮选择压缩包，或直接把压缩包拖进窗口（支持 `.zip` / `.7z` / `.rar`，可批量）
3. **启用 MOD**：点击 MOD 行右侧的开关；同一文件被多个 MOD 覆盖时按列表顺序生效
4. **启动游戏**：通过管理器或 Steam 正常启动即可

## 组件化 MOD

很多 MOD 压缩包内含多个可选版本（例如「蓝色 / 红色武器」「带箭矢 / 隐形箭矢」）。这类压缩包导入后会显示为**一个 MOD**：

- 点击 MOD 行封面旁的「▾ 组件 N/M」按钮，展开组件列表
- 每个组件有独立开关，可任意组合开启；冲突部分按列表顺序靠后覆盖靠前
- 用 ↑↓ 调整组件顺序，立即生效
- **仅总开关（MOD 行右侧开关）开启时，组件才会部署进游戏**
- 用新版压缩包点「↻ 更新 MOD」可原地更新，名称相同的组件会保留原来的开关状态

普通的单 MOD 压缩包导入方式完全相同，只是没有组件面板。

## 改对应装备

防具/武器模型替换类 MOD 可以把 MOD 改写到另一套游戏内装备（相当于换了穿戴对象）：

1. 先禁用该 MOD
2. 在右侧详情的「游戏内装备」区域点「修改」
3. 选择目标装备，确认即可；文件名和内部数据（含 PAK 内的路径）会一并改写

## 注意事项

- **崛起 / 荒野**：MOD 的 PAK 文件统一部署到游戏根目录的 `pak_mods` 文件夹，请确保 REFramework 前置已更新到支持的版本；世界（MHW）保持 nativePC 覆盖模式
- 开启「游戏运行时阻止修改」后，游戏运行中会禁止切换 MOD，避免文件写入冲突
- 游戏目录异常时可用底部「清理部署文件」一键移除当前启用的 MOD 文件
- 导入的压缩包默认保留在原位置，可在设置中改为复制/移动到工作区

## 常见问题

**MOD 启用了但游戏里没效果？**
检查组件化 MOD 的总开关和组件开关是否都已开启；崛起/荒野确认 REFramework 前置为支持版本；确认没有其他更高优先级的 MOD 覆盖了同一文件（调整列表顺序试试）。

**从旧版本升级后，原来的多 MOD 分组去哪了？**
新版本会把「同一压缩包导入的分组」自动合并为一个组件化 MOD，组件和开关状态原样保留；手动创建的分组不受影响。

**MOD 数据存在哪里？**
程序目录旁的 `data\` 文件夹。整个管理器是绿色的，把 `data\` 一起复制即可迁移。

**如何更新到新版本？**
下载新版 zip 解压覆盖（保留原 `data\` 文件夹），或直接在界面里用「↻ 更新 MOD」更新单个 MOD。

## 从源码构建

需要 Windows、.NET 9 SDK 和 Node.js 20+：

```powershell
git clone https://github.com/Noplch0/mh-mod-manager.git
cd mh-mod-manager
.\publish.ps1    # 产物在 dist\mh-mod-manager-<版本号>.zip
```
