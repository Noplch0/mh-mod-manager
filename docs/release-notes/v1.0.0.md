# mh-mod-manager v1.0.0

首个正式版本。面向《怪物猎人：世界》《怪物猎人：崛起》《怪物猎人：荒野》的 Windows MOD 管理器 —— 部署规则仍由 C# 核心负责，界面改为 Electron + 本地 API。

## 亮点

- **三作同管**：世界（Steam 582010）、崛起（1446780）、荒野（2246340）在同一个界面里切换管理。
- **界面与部署分离**：Electron 负责交互，部署逻辑由自包含的 C# 后端（本地 ASP.NET Core API）执行，规则与既有版本一致。
- **目录版分发**：后端以自包含目录形式打包（`PublishSingleFile=false`），发布物是压缩包而非单文件 exe，解压即用，也便于单独替换文件。

## 功能

### 导入与安装
- 支持 `.zip` / `.7z` / `.rar` 导入，可多选，也可以直接拖放到窗口。
- 从压缩包内的 module 配置与目录结构解析 MOD 的名称、版本、作者、分类，并提取预览图。
- 支持就地更新（in-place update）已安装的 MOD，保留原有启用状态与排序。

### 游戏目录探测
- 自动探测 Steam 安装位置（注册表 + `libraryfolders.vdf`），也可以在设置里手动指定游戏目录。
- 未安装的游戏会被识别出来并给出提示。

### MOD 与分组管理
- 启停单个 MOD，或在分组上一键启用 / 禁用整组。
- 上下移动调整加载顺序，分组顺序同样可调。
- 新建、重命名分组，把 MOD 移入 / 移出分组。
- 重命名 MOD、删除 MOD、一键清理部署产物。

### 部署规则
- **世界**：`nativePC` 文件覆盖模式。
- **崛起 / 荒野**：PAK 补丁模式，补丁编号在游戏已有补丁之后分配，避免与游戏本体或其他 MOD 冲突。
- 部署前自动备份，可从备份还原。

### 游戏内装备重映射
- 识别 MOD 中包含的装备（武器 / 防具 / 随从等），并列出对应文件清单。
- 在右侧详情的「游戏内装备」区域，可把识别到的装备改为另一套游戏内装备，管理器会同步改写相关 PAK 内的路径。
- 装备名称与文件清单已嵌入程序，运行时不依赖仓库根目录的 `data/`。

### 其它
- 打开 MOD 所在文件夹、查看预览图、跳转 MOD 主页。
- 启动游戏、检测游戏是否正在运行。

## 安装

1. 下载 `mh-mod-manager-1.0.0.zip`。
2. 解压到任意目录（建议非系统盘、路径不含中文）。
3. 运行 `mh-mod-manager.exe`。

数据目录位于 exe 同级的 `data/`，升级时保留该目录即可。

## 系统要求

- Windows 10 / 11 64 位
- 无需单独安装 .NET 运行时：压缩包内已附带自包含后端

## 校验

压缩包附带 `mh-mod-manager-1.0.0.zip.sha256`，可用以下命令校验：

```powershell
Get-FileHash .\mh-mod-manager-1.0.0.zip -Algorithm SHA256
```
