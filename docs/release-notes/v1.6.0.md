## 界面与设置

- 游戏切换与 MOD 操作改用图标工具栏。游戏设置和启动入口移到游戏图标的右键菜单。
- 组件可单独查看详情、文件和对应装备。通用设置新增四套配色和自定义背景图，可调整适配方式、不透明度、模糊和位置。
- Nexus 检查更新和选择下载文件移到详情顶部。未配置 Key 时禁用这两项；没有直链权限时仍可检查更新。MOD 来源网页也可手动设置。

## 部署与装备替换

- 只有启用的 MOD 新增实际覆盖，或覆盖优先级发生变化时才提醒。提示仅列出相关 MOD；导入禁用 MOD 时不扫描覆盖关系。
- 装备替换不会静默覆盖已有目标文件，失败会回滚。修复《怪物猎人：荒野》部分防具 AVP 显示替换成功但游戏内未生效的问题。
- 复制或移动模式下，源压缩包按游戏和 MOD 分开归档，避免同名 MOD 互相覆盖。

升级时请保留原 `data` 目录。
